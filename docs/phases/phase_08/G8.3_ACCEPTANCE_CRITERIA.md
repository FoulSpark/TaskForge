### 2. Comprehensive System Health Thresholds

During all G8.3 validation scenarios, the system must adhere to the following zero-defect limits:

* **Permanently Stranded Tasks:** `0` (Every task must reach `SUCCESS`, `DEAD_LETTER`, or `CANCELLED`).
* **Duplicate Committed Results:** `0` (At-most-once execution of terminal state mutations).
* **Stale-Worker State Mutations:** `0` (Fencing tokens must reject all zombie worker writes).
* **Invalid Task-State Transitions:** `0` (Task state transitions must strictly follow `LegalTransitions`).
* **Unaccounted Redis Deliveries:** `0` (All in-flight envelopes must be either acknowledged or reclaimed).
* **Successful Crash Recovery Rate:** `100%` of all injected crashes must recover without operator intervention.
* **Unexpected Worker Process Exits:** `0` (Excluding intentional test-injected process kills).
