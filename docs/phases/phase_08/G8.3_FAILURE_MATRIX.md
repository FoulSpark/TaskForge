### 2. Concurrency & Asynchrony Failure Modes

| Fault ID | Category | Anomaly Description | Injection Mechanism | Detection Mechanism | Recovery & Fencing Invariant | Required Final State | Test Suite |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **CF-01** | **Heartbeat Loss** | Worker process hangs or network partitions while holding lease | Suspend worker process (`SIGSTOP` simulation or sleep) | Redis heartbeat TTL expires; DB lease timestamp expires | Lease reaper reclaims task; replacement worker acquires with new `lease_token` | Replacement worker completes task; original suspended worker fenced on resume | `test_heartbeat_failover.py` |
| **CF-02** | **Zombie / Stale Worker Write** | Stale worker wakes up after lease expiration and attempts DB write | Frozen worker wakes and calls `update_status()` or `record_result()` | Repository row-lock check detects `task.lease_token != incoming_token` | Repository raises `PermissionError`; execution engine aborts stale execution | State remains pristine; replacement worker's output preserved; 0 corrupted rows | `test_lease_fencing.py`<br>`test_heartbeat_failover.py` |
| **CF-03** | **Multi-Process Thundering Herd** | 4 worker processes simultaneously claim tasks under high load | 1,000 tasks enqueued concurrently across 4 worker processes (16 threads) | Lua atomic script contention | Redis atomic `ZPOPMAX` and DB `FOR UPDATE SKIP LOCKED` prevent race conditions | All 1,000 tasks processed; 0 duplicate claims; 0 dropped tasks | `test_multiprocess_concurrency.py` |
| **CF-04** | **Uncooperative Timeout Hang** | Task handler ignores timeout and enters infinite loop or blocking I/O | Handler executes `while True: pass` or `time.sleep(100)` with `timeout_seconds = 1` | `future.result(timeout=1)` triggers `concurrent.futures.TimeoutError` | `ThreadPoolExecutor` shut down with `wait=False, cancel_futures=True`; execution engine returns immediately | Task marked `FAILED` or `RETRY_WAIT`; execution engine does not freeze | `test_execution_timeouts.py` |
| **CF-05** | **Retry Bound Exhaustion** | Faulty task fails repeatedly across multiple attempts | Handler unconditionally raises `RuntimeError` with `max_retries = 3` | Attempt counter reaches `max_retries` | Reaper / execution engine detects `retry_count >= max_retries`, transitions to `DEAD_LETTER` | Task terminal in `DEAD_LETTER`; 3 attempt records persisted with stack traces | `test_heterogeneous_workloads.py`<br>`test_reliability.py` |
| **CF-06** | **Graceful Shutdown Interruption** | SIGTERM received while processing long task | Worker receives `SIGTERM` / `SIGINT` while task with 2s duration is at 0.5s | Dispatcher signal handler intercepts signal; sets `stop_event` | Dispatcher stops dequeueing; waits for active task to finish within 10s grace period | Active task finishes cleanly to `SUCCESS`; Redis acked; clean process exit code 0 | `test_graceful_shutdown.py` |
